# Nexora ERP – Admin Panel (Frontend Console)

Dashboard Web App khusus platform owner / superadmin Nexora ERP.

## 🎯 Tujuan App
Aplikasi ini dikhususkan untuk tim manajemen platform Nexora ERP:
- Monitoring global kesehatan & metrik platform.
- Managing tenant onboarding & subscription status.
- System-wide configuration & global audit logs.

> **Catatan:** Terpisah dari `/apps/tenant-frontend/` yang ditujukan untuk pengguna tenant.
